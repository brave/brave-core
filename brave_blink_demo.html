Detecting engine...
    Apart from WebGPU, these are Chromium-only APIs. Brave keeps Google's ad-targeting ones off.

    How do we know?

      None of these read the User-Agent string. They test how the engine behaves, which a browser can't fake with a setting.

      Shields on Blink's network stack

        Ad and tracker requests are blocked before they leave the browser.

        Fingerprinting protection

          Brave adds tiny per-site noise to these values, so trackers get a different fingerprint on every site and every launch. Open this page via 127.0.0.1 instead of localhost to compare.

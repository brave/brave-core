# Reminders

Deliver helpful reminders to users on how to interact with Brave Ads.

| reminder  | explanation  |
|---|---|
| click the same ad multiple times  | Inform users they don't need to click to earn Brave Rewards  |
| connect an external wallet, i.e., Uphold or Zebpay¹  | Remind users to connect an external wallet to receive Brave Rewards  |

1. Implemented in the [browser layer](../../../browser/reminder/reminder_util.h).

Please add to it!

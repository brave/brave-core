# User Interaction Ad Events

Ad events are actions or interactions that occur within an advertisement, such as a user clicking the ad. Supported ad events are:

## New Tab Page Ads

- Served Impression: an ad was served
- Viewed Impression: an ad is visible to the user
- Clicked: a user clicks on an ad

## Notification Ads

- Served Impression: an ad was served
- Viewed Impression: an ad is visible to the user
- Clicked: a user clicks on an ad
- Dismissed: a user dismissed an ad
- Timed-out: a user did not interact with the ad

## Search Result Ads

- Served Impression: an ad was served
- Viewed Impression: an ad is visible to the user
- Clicked: a user clicks on an ad

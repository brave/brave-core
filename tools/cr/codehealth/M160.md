# M160 code health follow-ups

Tasks found by reviewing upstream changes in `159.0.8154.4..160.0.8162.1` (5068
commits) for regressions, deprecations and code-health migrations that apply to
Brave. Tick items off as they land.

## 1. Regressions

### The Google API keys and Obsolete System infobars bypass Brave's delegates

[de958f7853ff](https://chromium.googlesource.com/chromium/src/+/de958f7853ffce8b325cdd7b00cb0840470e27bb)
enables `kCentralizedInfoBarFramework` by default, and
[9fe2765c15ed](https://chromium.googlesource.com/chromium/src/+/9fe2765c15ed0e402ad8e8799442618b9f2860a2)
and
[b7faf9a7f90a](https://chromium.googlesource.com/chromium/src/+/b7faf9a7f90a0b0ab69c037ba3cfb4e780123e75)
flip its `kMigratedGoogleApiKeys` and `kMigratedObsoleteSystem` params to `true`
(`chrome/browser/infobars/infobar_features.cc:66,107`). `infobar_utils.cc` then
shows both through `BrowserInfoBarManager::Show()` and the specs at
`chrome/browser/ui/infobars/browser_infobar_registry.cc:164,180`, never reaching
the legacy `Create()` that Brave's swaps in
`chromium_src/chrome/browser/ui/startup/infobar_utils.cc` replace. Brave sets no
`google_api_key`, so upstream's "Missing Google API keys" infobar, linking to
the developers' how-to, is likely to show at startup; on Windows and macOS the
obsolete-system notice loses `BraveObsoleteSystemInfoBarDelegate`'s checkbox and
confirm dialog. Verified statically only. Earlier in the range,
[32256ad892b9](https://chromium.googlesource.com/chromium/src/+/32256ad892b912771138a9fd77a065e31bb200f4)
and
[0e700ff5a6be](https://chromium.googlesource.com/chromium/src/+/0e700ff5a6be7f224c02c309bafb37884f99a644)
migrated other infobars the same way. Extends the M157 parallel UI flags item
and M159's InfoBarSpec migration item.

- [ ] `chromium_src/chrome/browser/ui/startup/infobar_utils.cc:16-27`: pin
      `kMigratedGoogleApiKeys` and `kMigratedObsoleteSystem` false, or register
      Brave `InfoBarSpec`s for both delegates
- [ ] Test that `IsInfoBarMigrated()` is false for both and that no
      `GOOGLE_API_KEYS_INFOBAR_DELEGATE` infobar shows at startup without a key

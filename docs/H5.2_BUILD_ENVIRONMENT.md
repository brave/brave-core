## 0. 一句話

H5.2 的驗收是：**可對完整 Chromium + brave-core 樹執行 `gn gen`，並能定位 `//brave/bnes` target**。  
僅有工作區內的 `bnes-brave-core/bnes/*` 原始碼（H5.1）**不足**。

---

## 1. 工作區現況（本機盤點入口）

| 路徑 | 角色 |
|------|------|
| `bnes-brave-core/` | BNES 分叉的 brave-core（含 `bnes/`） |
| `bnes-brave-core/bnes/` | H5.1 安全 helper + `BUILD.gn` |
| `bnes-brave-browser/` | 上游 brave-browser 殼（目前僅版本／changelog；**不是**完整 chromium） |
| 完整 `chromium/src` | **尚未**出現在本工作區 |

**預檢命令（可重跑，非空殼）**：

```powershell
cd bnes-brave-core
powershell -ExecutionPolicy Bypass -File .\bnes\scripts\check-h5.2-env.ps1
```

| Exit | 意義 |
|------|------|
| 0 | 關鍵閘門全 PASS（含 `build.ninja`）→ 可進入 H5.3 |
| 2 | 盤點完成但有阻塞（**預期**於未 checkout 時） |
| 1 | 腳本錯誤 |

## 2. 建議目錄佈局（Windows）

Brave 慣例：`brave-core` 掛在 chromium 的 `src/brave`。

**推薦把完整 checkout 放在空間足夠的碟**（本工作區 S: 常不足；C: 通常較合適）：

```text
C:\bnes-browser\                 # 建置根（需 80GB+ 可用）
  src\                           # Chromium (gclient / pnpm init)
  src\brave\                     # junction/symlink → S:\Ai_Agent\BNES\bnes-brave-core
                                 # 或直接 clone 本分叉到此
```

建立 junction 範例（管理員或開發者模式）：

```powershell
# 先完成 chromium 到 C:\bnes-browser\src 後：
cmd /c mklink /J C:\bnes-browser\src\brave S:\Ai_Agent\BNES\bnes-brave-core
```

**不要**把完整 Chromium 下載到僅剩 ~20GB 的碟。

## 5. 初始化順序（達 `gn gen`）

> 下列會下載數十 GB，耗時依網路而定。**本文件不代替執行**；執行後必須把命令輸出摘要寫入進度報表。

```powershell
# A) 建置根（示例）
mkdir C:\bnes-browser -Force
cd C:\bnes-browser

# B) 依上游 brave 流程取得 chromium + depot_tools
#    常見路徑之一：以 brave-browser 殼 init，或在 src/brave 內 pnpm run init
#    本分叉工作區：
#    - 將 bnes-brave-core 掛到 src\brave
#    - cd src\brave
#    - pnpm install --frozen-lockfile   # 若 lock 可用
#    - pnpm run init                    # 拉取 chromium（巨大）

# C) 產生 out
#    pnpm run build -- ...  或上游文件中的 gn gen 參數
#    成功標誌：存在 out\...\build.ninja

# D) 重跑預檢
powershell -ExecutionPolicy Bypass -File .\bnes\scripts\check-h5.2-env.ps1
# 期望 exit 0
```

### H5.3 銜接（環境就緒後）

```text
ninja -C out/<dir> brave/bnes:unit_tests
# 或跑 brave_components_unittests（已 deps //brave/bnes:unit_tests）
```

具體 target 名稱以 `gn ls` 為準；通過後才可把 **H5.1／H5.3** 標為「已驗證（gtest）」。
